# Forge Ideate

Researcher uses this only when `STATUS.md` says `stage: ideate` and
`owner: Researcher`.

## Procedure

1. Read `governance/skills/forge-ideate/assets/template.md`.
2. Run `forge-loop-feynman` before searching prior work.
3. Choose exactly one path from `ANCHOR.md`.
4. Check Forge history and optional read-only brain/web evidence for
   duplication.
5. Select one narrow, useful, falsifiable question whose full proposal and
   research can each fit a 10-15 minute session.
6. If none qualifies, return NO-OP and write nothing.
7. Write one `forge/ideas/<slug>-r01.md` and return its path and ID to the
   Researcher loop.

## Gate

PASS only when the question is path-aligned, non-duplicate, testable, and
small enough for the short-session pipeline.
