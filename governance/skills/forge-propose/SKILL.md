# Forge Propose

Researcher uses this only when `STATUS.md` says `stage: propose` and
`owner: Researcher`.

## Procedure

1. Read the active idea and
   `governance/skills/forge-propose/assets/template.md`.
2. Run `forge-loop-feynman` on the method, not the answer.
3. Define the decision question, evidence needed, source plan,
   contradictions to seek, and acceptance criteria.
4. Scope the work so `forge-research` can complete it in one 10-15 minute
   session. Narrow it now if necessary.
5. Write one `forge/proposals/<slug>-rNN.md` and return its path and ID.

## Gate

PASS only when the method can answer the question honestly inside the time
box and the acceptance criteria are explicit.
