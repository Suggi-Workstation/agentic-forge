# Forge Feynman Loop

Use inside `ideate`, `research`, or `propose` for a provisional explanation,
explicit gaps, evidence checks, and a clearer synthesis. It writes nothing
to the Forge by itself and does not replace independent evaluation.

## Order

1. Read the selected pipeline's assignment, controls, LEARNINGS, and required prior work. At
   ideation, source discovery and duplicate/reflection checks may precede
   the question itself; do not pretend those sources were never read.
2. Before further targeted research, explain the candidate in plain words
   from your present understanding. Write it to a new scratch file
   `feynman-<pipeline-id>.md` in your scratch directory (`$TMPDIR` on
   Hermes), as a call of its own before any further source-consulting call;
   never keep it only in hidden reasoning. Label it provisional, not evidence.
3. Add to the same file the gaps, assumptions, alternative explanations,
   and disconfirmation, before step 4.
4. Read relevant Brain and primary web evidence. Update the gap list when
   sources reveal something new; never use the initial list to exclude
   inconvenient contradictions or leads discovered in reflections.
5. Rebuild the explanation from checked evidence. Separate what is known,
   inferred, disputed, and still unknown; simplify without hiding limits.
6. Delete the scratch file; leave a refused deletion to the scratch
   directory's automatic pruning and do not retry it another way. Return
   the result to the calling stage and its template gate. Meaningful
   uncertainty can be reported for evaluation; do not force closure.

## Gate

Before returning, PASS requires a provisional explanation and gap list
written to the scratch file before further targeted research, honest
source ordering, checked decisive premises or explicit unknowns, and
updated gaps/contradictions. Otherwise HALT the claim or narrow the work.
A confident explanation alone never verifies it.

Repository writes stay in the Forge. External sources are read-only.
