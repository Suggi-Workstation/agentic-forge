# Forge Feynman Loop

Use inside a Researcher stage for a provisional explanation, explicit gaps,
evidence checks, and a clearer synthesis. It writes nothing by itself.
It does not replace the independent Analyst evaluation.

## Order

1. Read the assignment, controls, LEARNINGS, and required prior work. At
   ideation, source discovery and duplicate/reflection checks may precede
   the question itself; do not pretend those sources were never read.
2. Before further targeted research, explain the candidate in plain words
   from your present understanding. Label this as provisional, not evidence.
3. Name gaps, assumptions, alternative explanations, and disconfirmation.
4. Read relevant Brain and primary web evidence. Update the gap list when
   sources reveal something new; never use the initial list to exclude
   inconvenient contradictions or leads discovered in reflections.
5. Rebuild the explanation from checked evidence. Separate what is known,
   inferred, disputed, and still unknown; simplify without hiding limits.
6. Return the result to the calling stage and its template gate. Meaningful
   uncertainty can be reported for Analyst assessment; do not force closure.

## Gate

Before returning, PASS requires a provisional explanation before further
targeted research, honest source ordering, checked decisive premises or
explicit unknowns, and updated gaps/contradictions. Otherwise HALT the
claim or narrow the work. A confident explanation alone never verifies it.

All writes stay in the Forge. External sources are read-only.
