# Forge Build

Researcher uses this only when `STATUS.md` says `stage: build` and
`owner: Researcher`.

## Procedure

1. Read the active PASS evaluation and
   `governance/skills/forge-build/assets/template.md`.
2. Run `forge-loop-feynman` on the proposed synthesis, then read the earlier
   research chain.
3. State the recommendation, evidence, simplest implementation plan,
   acceptance tests, worst case, rollback, limitations, and human questions.
4. For Agent Systems, produce a concrete design or skill/package proposal.
5. For Value-Investing Systems, produce a Buffett-Munger-aligned framework,
   checklist, or model design, not a security recommendation.
6. Keep the package reviewable within one 10-15 minute session.
7. Write one `forge/builds/<slug>-rNN.md` and return its path and ID.

## Gate

PASS only when the build is evidence-backed, simple, testable, reversible,
and ready for independent verification.
