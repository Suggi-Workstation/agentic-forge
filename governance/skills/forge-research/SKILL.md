# Forge Research

Researcher uses this only when `STATUS.md` says `stage: research` and
`owner: Researcher`.

## Procedure

1. Read the active proposal and
   `governance/skills/forge-research/assets/template.md`.
2. Run `forge-loop-feynman`, then execute only the approved evidence plan.
3. Prefer primary sources. Independently corroborate consequential claims.
4. Seek contrary evidence and separate fact from inference.
5. Optional `query-brain-vps` use is search/read only. Never run its watcher,
   clone, rebuild, repair, or write fallback from a Forge session.
6. Record sources, findings, contradictions, gaps, and confidence.
7. Write one `forge/research/<slug>-rNN.md` and return its path and ID.

## Gate

PASS when the proposal was executed within 10-15 minutes and every material
claim is supported, contradicted, or marked unresolved.
