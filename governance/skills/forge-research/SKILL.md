# Forge Research

Produce an evidence report, not an implementation or a verdict on yourself.
Run through `forge-loop-research` at `research`. Read `forge/protocol.md`
and `governance/template-research.md` before writing.

## Procedure

1. Read the root and current idea, LEARNINGS, and the exact STATUS input.
   On revision, also read the evaluation/review findings and affected prior
   research or proposal. Confirm a single pipeline and the specific questions.
2. Use `governance/skills/forge-loop-feynman/SKILL.md`: provisional explanation,
   gaps, evidence gathering, fresh synthesis. Answer each material evaluation
   or review finding with evidence, a revision, or a reasoned disagreement;
   never silently drop an objection. Label unresolved issues as blocking.
3. Query relevant Brain knowledge and use `web_search` / `web_extract`
   for independent primary sources. Read sources, not search snippets;
   date claims, distinguish observation from inference, and check source
   independence and contrary evidence. Source access is read-only.
4. Compare existing solutions, a smaller change, and doing nothing. For
   investing questions, use the ANCHOR's Buffett/Munger criteria rather
   than generic optimization. Check decisive premises against independent
   evidence, or mark them unknown; never fabricate a source quota.
5. Write one report in `forge/research/` under the template's checklist.
   Negative findings and a well-documented lack of evidence are legitimate
   results for evaluation. A timed-out or unperformed investigation
   is not a completed report; use the protocol's resume handling instead.
6. Return the artifact path to the loop for the protocol handoff. Do not
   issue ADVANCE, write a proposal, or update LEARNINGS yourself.

## Verification

Before writing, PASS requires the correct inputs, checked and accurately
cited sources, explicit uncertainty/contradictions, responses to feedback,
and every template item. Otherwise HALT the artifact; the loop preserves
an honest resume point. Evidence that refutes the hypothesis is not a
procedural failure and must not be hidden to obtain an affirmative result.
