# Forge Research Evidence-Package Gate

## Question and Value

Can one conditional evidence-package gate in the Forge research template expose
missing instruments, fixtures, per-case results, and separate comparator or
reader records before a procedural comparison reaches evaluation, while allowing
ordinary source research and independently decidable negative findings to finish
without a ceremonial package?

The target is `governance/template-research.md` and, only if the template cannot
make the condition executable by itself,
`governance/skills/forge-research/SKILL.md`. The current template requires
reproducible source checks to be documented, but it does not state when the
instrument, inputs, invocation, raw outputs, and each comparator's application
record must remain recoverable.[3] `LEARNINGS.md` already states that method at
high confidence, yet later research again reached evaluation without separate
reader outputs.[2][6] This is direct ANCHOR Path A work on converting a confirmed
method lesson into a smaller, locally visible research gate.[1]

The practical value is earlier and more proportionate routing. The first
bounded-freshness report depended on scratch-only classifier bytes and received
REVISE; the corrected report embedded its classifier, fixtures, invocation, raw
output, and hashes, after which two evaluator runs reproduced all 22 declared
cases.[4] The first claim-map report similarly omitted exact instrument bytes
and separate reader records and received REVISE. Its corrected package then made
a negative comparison checkable and showed that the proposed map added no
disclosed detection over the full current proposal checklist.[5] A later
retained-earnings report again lacked separate reader outputs, but the evaluator
reproduced the negative decision directly from the rules, primary records, and
arithmetic, so another cycle was unnecessary.[6] A useful gate must distinguish
a material missing evidence package from a procedural claim that can be
withdrawn or given no weight.

The provisional hypothesis, formed after those artifacts and the current
research contract were compared, is that one conditional checklist item can
make the existing lesson operational: preserve the complete package when a
procedural comparison, reproduction claim, or independent-reader result is
material to the conclusion; otherwise narrow or withdraw that claim. A credible
alternative is that the existing template and mandatory LEARNINGS read already
supply the full semantic rule, so another line would add no detection and would
not change author behavior. The idea is not worth pursuing if a fair reading of
the current gate classifies the cases equally, if the candidate blocks ordinary
research or the independently decidable retained-earnings result, if its benefit
requires a large map or executable checker, or if record burden exceeds the
missing-evidence cost.

## Origin and Prior Work

This is direct ideation under ANCHOR Path A, Agent Systems. Discovery preceded
the provisional explanation. The current board, active logs, all current files
in `forge/ideas/`, `forge/proposals/`, and `forge/graveyard/`, reachable
historical tier paths, the Forge index, Brain prior work, the Investing Hub's two
company reports and frameworks, and primary artifact-review guidance were
checked before selecting the question.

The closest current work is the closed claim-to-verification-map pipeline. It
tested a proposal-stage row map for normative claims, operations, predicates,
and controls. Once its comparator used the full semantic proposal checklist,
the map found no additional disclosed blocker, produced divergent inventories
and unsupported findings, and imposed much larger records; the evaluation
returned REJECT.[5] This idea does not reopen that map. It targets whether the
research artifact preserves the evidence needed to support a procedural result,
uses no claim inventory, and requires the no-change baseline to receive the same
full semantic reading.

There is changed evidence after that closure. The retained-earnings pipeline
again reported a separate-reader comparison without preserving the readers'
unmerged outputs, even though the high-confidence lesson was already available.
The evaluator could still decide the bounded question without that comparison
and therefore gave the reader agreement no additional weight rather than
requesting another cycle.[6] That case adds the claim-narrowing boundary that the
proposal-map experiment did not test: missing procedural evidence should not
force work that is immaterial to an otherwise independently supported result.

The bounded-freshness pipeline supplies both a negative and a positive control.
Its first report shows a material package gap that blocked advancement; its
corrected report shows a compact complete package that an evaluator could
extract and rerun exactly.[4] The claim-map correction supplies a second
positive control for preservation even though the tested method itself failed
on decision value.[5] These outcomes separate evidence availability from an
affirmative research verdict.

The duplicate search also checked historical work reachable after the repository
reset. The transaction-checker pipeline concerned post-write agreement among an
artifact, STATUS, and progress event and closed DEFER after a valid-record false
rejection. The unattended-command pipeline concerned authoritative command
denials and route selection, reached READY, and has no explicit recorded human
disposition. The current bounded-freshness discovery remains pending human
review. None asks whether a conditional research-template gate should preserve
or explicitly disclaim a material procedural evidence package.[9]

Brain prior work says an agent evaluation contract includes the harness,
environment, grader, protocol, and raw run artifacts, and that a trace supports
only the operations and fields it actually records.[7] ACM's current artifact
review guidance likewise treats documented, complete, exercisable artifacts and
verification evidence as distinct from the written result alone.[8] These
sources support testing evidence availability; they do not prove that one Forge
template line will change author behavior.

The strongest alternative candidate was another unattended-command safe-route
study prompted by repeated blocked inline probes and cleanup attempts. It lost
because the historical unattended-command proposal already covers denial
authority, route selection, and no-bypass behavior and remains without an
explicit human disposition.[9] Later incidents may inform that pending decision,
but they do not justify a renamed pipeline. The selected evidence-package
question instead has a new post-closure case, a different lifecycle point, and a
bounded no-map comparison.

No explicit accepted Forge proposal was found in the active or reachable
historical decision evidence inspected. The current bounded-freshness discovery
is awaiting review; READY is not approval.[9]

## Research Plan

Run one frozen retrospective classification with a small prospective check. Do
not edit the template, skill, lessons, reviewed artifacts, or runtime during
research.

1. Freeze the current research template, research skill, high-confidence lesson,
   and exact target corpus: bounded-freshness r01 and r02 with both evaluations;
   claim-map r01 and r02 with both evaluations; and retained-earnings r01 with
   its evaluation. Add one ordinary source-synthesis report without a procedural
   comparison as a not-applicable control.
2. Before grading any target, write the full semantic baseline for the current
   template's `reproducible source checks are documented` item. Then freeze one
   candidate conditional rule. It may require recoverable instrument or rule
   bytes, inputs or fixtures, environment and invocation, per-case raw results,
   and unmerged comparator or reader outputs only when a procedural comparison,
   reproducibility claim, or reader agreement materially supports the result.
   It must permit an explicit claim withdrawal or no-weight statement when the
   result is independently decidable.
3. Have separate cold readers apply the baseline and candidate to every target
   without using the later verdict as an answer key. Preserve each reader's
   classifications and reasons before opening the evaluations. Classify each
   case as `package required`, `claim narrowing sufficient`, `not applicable`,
   or `package complete`; record omissions and disagreements rather than
   reconciling them away.
4. Open the evaluations and compare both gates with the actual evidence defects
   and dispositions. Check whether the candidate uniquely identifies a material
   missing package in the two REVISE cases, accepts the two corrected packages,
   and routes the retained-earnings reader claim to narrowing rather than an
   unnecessary correction. A later verdict is comparison evidence, not proof
   that the verdict was infallible.
5. Give both readers one scratch-only synthetic research excerpt containing a
   persuasive aggregate result but no recoverable per-case outputs, plus one
   ordinary source-synthesis excerpt. Check whether the candidate changes the
   evidence classification without falsely requiring a package for the ordinary
   excerpt. This is a comprehension check, not a measured future defect rate.
6. Measure candidate words, required record classes, reader agreement,
   classifications changed over the full current baseline, false blockers, and
   estimated artifact burden from the actual corrected packages. Compare doing
   nothing, a single conditional template item, one accompanying research-skill
   sentence, the rejected proposal map, and an executable checker. The map and
   checker remain excluded from any recommendation unless separately justified.
7. Stop without a proposal if the full current gate performs equally, if the
   candidate cannot distinguish material evidence from optional corroboration,
   if corrected or ordinary controls are blocked, if independent readers cannot
   apply it consistently, or if useful wording cannot remain one checklist item
   and at most one procedure sentence.

Research supports a proposal only if the candidate adds a decision-relevant
classification over the fairly applied current gate, catches both known
material preservation defects, passes both corrected-package controls, assigns
no package to the ordinary control, and permits claim narrowing for the
independently decidable retained-earnings result. Any proposal must remain a
concise, reversible template or template-plus-skill clarification. It must not
claim a measured reduction in future defects, create an executable validator, or
change LEARNINGS, runtime, approval policy, or completed artifacts.

Confidence is low. Repeated artifacts show that package preservation can be
material and that the current high-confidence lesson has not always been
applied.[2][4][5][6] Confidence remains low because the comparison is mainly
retrospective, the candidate wording has not been tested, the current semantic
gate may already be sufficient, and author behavior is not measured. Confidence
would rise if cold readers find a unique, reproducible classification benefit
without false blockers or large record cost. It would fall if the current gate
performs equally or the conditional rule recreates the burden and disagreement
of the rejected proposal map.
